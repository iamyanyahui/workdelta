核心功能

不打断工作，
也不会忘记工作。

工迹在后台把零散的文件变化，整理成一条真正看得懂的工作记录。

⌁
01

自动生成工作时间线

编辑、保存、切换文件时无需手动点击计时。相近的变化会合并成工作时段，15 分钟无活动后自动分段。

02

一键导出日报

把今天的项目、时段和改动文件整理成中文 Markdown，复盘和汇报都更轻松。

03

内容检查点

使用隔离的 Git 镜像保留文本内容检查点，不会修改源项目，也不会在项目中创建 .git。

安静驻留后台

关闭窗口后继续在系统托盘运行，也可以选择开机自动启动。

常见问题

开始之前，
你可能想知道。

工迹会监控我所有的电脑操作吗？

不会。它只观察你主动添加的项目文件夹，不记录键盘、鼠标、应用使用情况或网页浏览记录。

它会修改我的 Git 仓库吗？

不会。内容检查点保存在独立的本地镜像中，源项目不会被初始化或修改 Git 配置。

工作时间是如何计算的？

工迹根据有效文件变化推断项目活动时间。相近变化会归入同一时段，超过 15 分钟无活动则开始新的时段。它适合回顾工作，不等同于考勤计时。

目前支持哪些系统？

当前版本面向 64 位 Windows 10 和 Windows 11，应用界面使用原生 WPF 构建。
